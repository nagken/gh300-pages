## Readiness checklist

- [ ] You can recite the **5 plans** + IP indemnity + content exclusions + knowledge bases availability.
- [ ] You can answer "where do I configure content exclusions?" without checking.
- [ ] You can compare **Copilot Edits** vs **Copilot Workspace** vs **Copilot Chat**.
- [ ] You can list **all 8 slash commands** (`/explain`, `/fix`, `/tests`, `/doc`, `/optimize`, `/clear`, `/help`, `/new`).
- [ ] You can list **all chat participants** (`@workspace`, `@terminal`, `@vscode`, `@github`).
- [ ] You can explain **why `.gitignore` does NOT block Copilot**.
- [ ] You can describe the **public code filter** (threshold + 3 modes).
- [ ] You can list the **default training data settings** by plan tier.
- [ ] You can explain **TDD with Copilot** end-to-end.
- [ ] You can list **6 prompt-crafting anti-patterns** + their fixes.
- [ ] You can list **3 risks of LLM-generated code** + mitigations.
- [ ] You can name an **audit log event** for Copilot.
